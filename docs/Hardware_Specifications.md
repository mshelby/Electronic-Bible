# Hardware Specifications

## Audio Components

| Component | Specification | Notes |
|-----------|---------------|-------|
| **Microphone Array** | 4-mic circular array | Beamforming for voice isolation |
| **Speaker Driver** | 3" full-range driver | Optimized for midrange clarity |
| **Tweeter** | 1" silk dome tweeter | Upward-firing for room fill |
| **Amplifier** | Class D stereo amplifier | High efficiency, low distortion |
| **DAC** | 24-bit/96kHz stereo DAC | High-resolution audio output |

## Processing Unit

| Component | Specification | Notes |
|-----------|---------------|-------|
| **Main Processor** | ARM Cortex-A55 quad-core | Low power, sufficient for audio processing |
| **RAM** | 2GB LPDDR4 | Sufficient for offline text library |
| **Storage** | 32GB eMMC | Local text library storage |
| **WiFi** | 802.11ac WiFi | Local network connectivity |
| **Bluetooth** | 5.0 BLE | For peripheral devices |

## Power

| Component | Specification | Notes |
|-----------|---------------|-------|
| **Battery** | 5000mAh Li-Po | ~8 hours continuous playback |
| **Charging** | USB-C PD 15W | Fast charging capability |
| **Standby** | <1W consumption | Ultra-low power idle |

## Physical Dimensions

| Dimension | Value | Notes |
|-----------|-------|-------|
| **Height** | 175 mm | Compact form factor |
| **Width** | 200 mm | Spherical barrel design |
| **Depth** | 150 mm | Shallow profile |
| **Weight** | ~800g | Substantial feel for stability |
| **Wall Thickness** | 2.5 mm | PETG construction |

## Connectivity

- **Local Network**: Home Assistant integration
- **Audio Output**: 3.5mm jack, Bluetooth A2DP
- **Control**: Touch-sensitive top panel, voice commands
- **Sync**: Encrypted local database sync via WiFi

## Materials

- **Main Body**: Matte PETG (Concrete Gray)
- **Trim Rings**: Matte PETG (Navy Blue)
- **Gaskets**: TPU 95A (Black)
- **Fasteners**: N52 Neodymium Magnets, M3 screws
